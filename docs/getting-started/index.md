# Getting Started

This section walks you through building and setting up a SpoolmanScale from scratch. If you already have a device, jump straight to [OTA Update](../firmware/ota.md).

---

## Build Overview

```
Step 1 → Buy parts       (Bill of Materials)
Step 2 → Wire everything  (Wiring Guide)
Step 3 → Print the case   (MakerWorld)
Step 4 → Flash firmware   (Web Flasher or USB)
Step 5 → First setup      (WiFi → Backend → Calibrate)
```

---

## What you need

- A WT32-SC01 Plus (ESP32-S3 + 3.5" display)
- A PN532 NFC breakout board
- A SparkFun NAU7802 scale ADC
- A 5 kg single-point load cell
- A 3D printer (for the enclosure)
- A USB-C cable + 5V power supply

See the full [Bill of Materials](bom.md) with exact parts and links.

---

## Time Estimate

| Phase | Time |
|---|---|
| Ordering parts | 1–7 days shipping |
| Printing enclosure | ~4–6 hours |
| Wiring + assembly | ~2 hours |
| Flashing + setup | ~20 minutes |

---

## Difficulty

!!! note "Skill level"
    SpoolmanScale requires basic soldering skills and comfort with ESP32 flashing. No programming knowledge required — the firmware is pre-built.
